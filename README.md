# UNIT 99-E OS

Web view and APK host for the Android head unit.

- View: https://austindrew2021-code.github.io/UNIT99-E_OS/
- Install: https://github.com/austindrew2021-code/UNIT99-E_OS/releases/download/1.2.16/UNIT99-E_OS_1.2.16.apk
- Same file on Pages: https://austindrew2021-code.github.io/UNIT99-E_OS/pipos.apk

`com.pipcar.launcher` version 1.2.16, 19.3 MB. Open the install link in the device browser and allow the install. Set Pip-OS as the Home app when Android asks.

STAT and INV on the site are the on-screen view. The APK tab and the install bar download the real launcher.
